# Локальный запуск через Docker

Локальная версия сайта на `localhost`, полностью изолированная от прода.
Базы (Postgres + Redis) крутятся в Docker на твоём ПК. Vercel/Railway/Neon/
Upstash это **не трогает** — они берут настройки из своих панелей.

## Первый раз (настройка)

1. Установи **Docker Desktop**: https://www.docker.com/products/docker-desktop/
   Скачай, поставь как обычную программу, запусти. Дождись, пока в трее
   значок кита перестанет мигать (Docker готов).

2. В папке проекта один раз выполни:
   ```
   npm install
   npm run setup:local
   ```
   `setup:local` поднимет базы, создаст таблицы и зальёт словарь.

3. Запусти сайт:
   ```
   npm run dev
   ```
   Открой http://localhost:3000

## Каждый следующий раз

```
npm run db:up     # поднять базы (если Docker Desktop запущен)
npm run dev       # запустить сайт
```

Можно и просто `npm run dev` — но базы (`db:up`) должны быть подняты,
иначе сайт не подключится к данным.

## Команды

| Команда | Что делает |
|---|---|
| `npm run db:up` | Поднять локальные Postgres + Redis |
| `npm run db:down` | Остановить базы (данные сохраняются) |
| `npm run setup:local` | Поднять базы + миграции + словарь (первый раз) |
| `npm run db:studio` | Открыть просмотрщик базы в браузере |
| `npm run dev` | Запустить web (:3000) и ws (:3001) |

Стереть локальные данные начисто: `docker compose down -v`, затем
`npm run setup:local`.

## Где какие настройки

- **`.env`** — локальные настройки (смотрят на Docker-базы). В git не
  попадает. Только для запуска на твоём ПК.
- **`.env.prod.backup`** — боевые строки подключения (Neon/Upstash).
  Если когда-нибудь надо подключиться к проду локально — скопируй
  значения из этого файла в `.env`. Обычно не нужно.
- **Прод** берёт настройки из панелей Vercel и Railway — ни `.env`, ни
  локальный запуск на него не влияют. Боевой сайт меняется только после
  `git push` в ветку `main`.

## Если что-то не так

- **«Docker не найден» / команда `docker` не работает** — Docker Desktop
  не установлен или не запущен. Запусти Docker Desktop и подожди.
- **Порт 5432 или 6379 занят** — у тебя уже стоит другой Postgres/Redis.
  Останови его или поменяй порт в `docker-compose.yml` (левое число,
  напр. `"5433:5432"`), и тогда в `.env` поправь порт в `DATABASE_URL`.
- **Сайт грузится, но истории/игр нет** — не выполнен `npm run setup:local`
  (нет таблиц/словаря).
