# Скриншоты для README

Четыре картинки в блоке под шапкой README. Имя файла — это ссылка из README:
переименуешь файл, не поправив README, — картинка пропадёт.

| Имя файла | Что на нём |
|---|---|
| `hub.png` | Главная `/` — карточки обеих игр и поле для кода комнаты |
| `alias-landing.png` | Страница `/alias` — кнопки начала партии и «Как играть» |
| `alias-round.png` | Алиас, экран объясняющего: слово, таймер, счёт раунда |
| `mafia-results.png` | Итоги партии Мафии: кто кем был и хроника ночей |

## Чего не хватает

Игровых экранов самой Мафии: ночь (сетка игроков и выбор жертвы) или дневное
голосование. Сейчас Мафия показана только итогами — по ним не видно, как в неё
играют. Если добавишь, положи файл как `mafia-night.png` и допиши строку в
таблицу README.

## Как снимать

- **Ширина окна браузера 1100–1300 px.** Это главное правило, и нарушить его
  легче всего: снимать хочется на весь монитор, а страницы центруют содержимое
  в узкой колонке — у итогов Мафии она 920 px, у хаба около 880. На кадре в
  1920 px вокруг остаётся по 500 px пустоты с каждой стороны, в таблице README
  такой снимок выглядит мелким рядом с теми, где содержимое заполняет кадр.
  Узкое окно убирает пустоту само, без обрезки.
- Мобильную ширину тоже не берём: в таблице из двух колонок она выглядит
  узкой полоской.
- **Тёмная тема** — обе игры нарисованы под неё, Мафия особенно.
- **Настоящие данные, а не заглушки**: живые имена игроков, ненулевой счёт,
  заполненные команды. Пустой экран выглядит как незаконченный проект.
- **PNG**, без теней окна браузера и без адресной строки.
- Держать файлы **меньше мегабайта** — при необходимости сжать (tinypng и
  подобные). Гигантские PNG раздувают клон репозитория.

## Что не снимать

Экраны с ролями чужих игроков и всё, где видно чужие имена без их согласия.
