# Скриншоты для README

Четыре картинки в блоке под шапкой README. Пока файлов нет, картинки не
отображаются — README при этом читается нормально.

| Имя файла | Что снять |
|---|---|
| `hub.png` | Главная `/` — две карточки игр и поле для кода комнаты |
| `alias-round.png` | Алиас, экран объясняющего: слово, таймер, счёт |
| `mafia-night.png` | Мафия, ночь: сетка игроков и выбор жертвы |
| `mafia-results.png` | Итоги партии Мафии: кто кем был и хроника |

## Как снимать

- **Ширина 1200–1600 px**, десктопная раскладка. Мобильные скриншоты в таблице
  из двух колонок выглядят узкими полосками.
- **Тёмная тема** — обе игры нарисованы под неё, Мафия особенно.
- **Настоящие данные, а не заглушки**: живые имена игроков, ненулевой счёт,
  заполненные команды. Пустой экран выглядит как незаконченный проект.
- **PNG**, без теней окна браузера и без адресной строки.
- Держать файлы **меньше мегабайта** — при необходимости сжать (tinypng и
  подобные). Гигантские PNG раздувают клон репозитория.

## Что не снимать

Экраны с ролями чужих игроков и всё, где видно чужие имена без их согласия.
