# Старый главный экран Алиаса

Здесь лежит предыдущая версия страницы `/alias` — та, что была до перехода
на макет `project-context/mafia-design/alias/screen-landing.jsx`.

Сохранено на случай, если понадобится что-то оттуда вернуть или сравнить.
В приложении этого кода больше нет.

## Что внутри

| Файл | Что это |
|---|---|
| `page.tsx` | компонент страницы целиком, как он лежал в `apps/web/src/app/alias/page.tsx` |
| `styles.css` | его стили, вырезанные из `apps/web/src/app/globals.css` (классы `.home-*`, `.hs-*`, `.feat`, `.outline-text`) |

## Как выглядел

Две колонки: слева заголовок «АЛИАС В РЕАЛЬНОМ ВРЕМЕНИ», три кнопки-CTA
(онлайн-комната, одно устройство, вход по коду) и строка преимуществ;
справа — декоративная сцена из наклонённых карточек: слово «Титаник» с
таймером, плашки «угадано»/«пропуск», табло счёта и код комнаты. Правая
колонка пряталась ниже 980px.

Заменён потому, что после появления хаба на `/` эта страница дублировала
его роль: она была свёрстана как главная страница сайта, а не как лендинг
одной из двух игр.
