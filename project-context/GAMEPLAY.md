# Правила и параметры игр

Что именно реализовано, со всеми числами. Все значения взяты из
[`packages/shared/src/constants.ts`](../packages/shared/src/constants.ts) и
[`mafia.ts`](../packages/shared/src/mafia.ts) — это единственный источник
истины, откуда их берут и сервер, и интерфейс.

# Алиас

Одна команда объясняет слова, другая угадывает. Побеждает первая, набравшая
нужное число очков.

## Составы

| | Значение |
|---|---|
| Команд | 2–6 |
| Игроков в команде | 2–6 |
| **Всего человек** | **3–36** |
| Зрителей | без ограничений |

Минимум в три человека даёт режим «втроём»; командами минимум четверо — две
команды по двое.

## Два формата

**Командный.** Ход переходит по кругу между командами. Победа считается только
в конце круга, когда у всех было поровну ходов.

**Втроём.** Три места по одному игроку, круг из шести ходов:

| ход | объясняет | угадывает | отдыхает |
|---|---|---|---|
| 1 | 1 | 2 | 3 |
| 2 | 2 | 3 | 1 |
| 3 | 3 | 1 | 2 |
| 4 | 2 | 1 | 3 |
| 5 | 3 | 2 | 1 |
| 6 | 1 | 3 | 2 |

Каждый дважды объясняет, дважды угадывает, дважды отдыхает. **Очки получают
оба** участника пары — угадывание общая заслуга.

## Два способа играть

- **Онлайн** — комната по шестизначному коду, у каждого свой телефон. Слово
  видит только объясняющий.
- **Локально** — одно устройство на компанию, передаётся по кругу. Интернет не
  нужен.

## Настройки

| Настройка | Варианты | По умолчанию |
|---|---|---|
| Время раунда | 30 / 45 / 60 / 90 / 120 с | 60 с |
| Цель по очкам | 25 / 50 / 75 / 100 | 50 |
| Штраф за пропуск | вкл / выкл | **выкл** |

Сервер принимает и не-пресетные значения: раунд 10–300 с, цель 0–1000.

## Ход раунда

1. Объясняющий видит слово только у себя.
2. Свайп вправо — угадано, влево — пропуск. Попытки не ограничены.
3. По сигналу — **экран итогов**: список показанных слов. Объясняющий снимает
   спорные, счёт пересчитывается на глазах у всех, и только после подтверждения
   ход переходит дальше.
4. Угаданное — плюс очко. Пропуск бесплатный, если штраф не включён.

## Словарь

**8134 уникальных слова**: 8 подборок с 35 темами плюс 3 уровня сложности.

| Подборка | Тем | Слов |
|---|---|---|
| Классика | 5 | 1259 |
| Мир вокруг | 4 | 844 |
| Про людей | 4 | 861 |
| Будни | 5 | 1013 |
| Поп-культура | 6 | 1293 |
| Челлендж | 5 | 1135 |
| Праздники | 4 | 766 |
| Детям | 2 | 478 |
| **Уровни сложности** | 3 | 3864 |

Наборы комбинируются в любом сочетании, минимум один. Темы и уровни намеренно
пересекаются, поэтому счётчик на экране выбора показывает **уникальные** слова,
а не сумму: «Животные» плюс «Лёгкий уровень» — 1442 слова, а не 1605.

Внутри партии слово не повторяется — сыгранные отсекаются при выдаче.

У четырёх тем есть сезон: Новый год, Хэллоуин и Лето поднимаются в списке в свой
месяц.

# Мафия

Город спит, мафия убивает, днём город голосует. Ведущего заменяет сервер.

## Составы

| | Значение |
|---|---|
| Игроков | 5–16 |
| Зрителей | без ограничений |

Зрителем становится тот, кто зашёл после старта, и выбывший игрок. При «сыграть
ещё» подсевшие зрители возвращаются в игру — но не больше шестнадцати всего.

## Роли

| Роль | Команда | Что делает |
|---|---|---|
| **Мафия** | мафия | ночью выбирает жертву вместе с напарниками |
| **Дон** | мафия | разбивает ничью в голосовании мафии |
| **Шериф** | город | одна проверка за ночь: мафия или нет |
| **Доктор** | город | лечит одного за ночь |
| **Маньяк** | сам за себя | убивает по ночам |
| **Мирный** | город | ничего не умеет ночью |

Ограничения, которые держит сервер:

- мафия **не может** выбрать целью мафию или дона;
- дон появляется, только если мафий двое и больше — он одна из них, а не сверх;
  по умолчанию выключен, а при одной мафии тумблер в настройках недоступен;
- доктор не лечит одного и того же две ночи подряд, себя — один раз за партию;
- шериф не может проверить себя, проверка за ночь одна и необратима;
- шерифа, доктора и маньяка — по одному максимум.

**Состав мафии.** Автоматически — `floor(игроков / 3)`, минимум один: девять
игроков дают трёх мафий, семь — двух. Вручную — от 1 до 8. Один мирный
остаётся гарантированно.

**Как мафия выбирает жертву.** Побеждает большинство голосов. Голоса
разделились поровну — вступает Дон, но только если его собственная цель среди
спорных; иначе ничью решает жребий. Дона нет, он выбыл или промолчал — жребий.
То есть Дон не начальник, а разрешитель споров: при двух мафиях он решает
всегда, при трёх — каждый раз, когда команда не договорилась.

## Фазы

```
ЛОББИ → РАЗДАЧА РОЛЕЙ → ЗНАКОМСТВО → НОЧЬ → УТРО → ОБСУЖДЕНИЕ → ГОЛОСОВАНИЕ
                                       ↑                             ↓
                                       └──── ПОСЛЕДНЕЕ СЛОВО ←───────┘
```

**Знакомство** — обсуждение до первой ночи. Изгонять в нём некого: люди просто
успевают поговорить и осмотреться, прежде чем кто-то начнёт погибать.

**Пропустить обсуждение** может не хост, а стол: у каждого живого есть
переключатель, и когда его нажали все живые, фаза кончается досрочно. Кнопка
была хостовской, но погибший хост уходит на экран наблюдателя, где её нет, а
пропавший из сети не нажмёт и подавно — обсуждение досиживали до таймера.

В голосовании, кроме игроков, есть вариант **«никого не изгонять»**. Он
считается наравне с остальными: набрал больше всех — день заканчивается без
изгнания, и голоса за него видны так же, как голоса за игрока.

Голоса равны — сразу второй тур, и голосовать в нём можно только за тех, кто
набрал поровну. Равенство повторилось — никто не выбывает и наступает ночь.

## Победа

| Побеждает | Когда |
|---|---|
| Город | не осталось ни мафии, ни маньяка |
| Мафия | мафии столько же, сколько всех остальных |
| Маньяк | мафии нет, а горожан не больше одного |

## Настройки

| Правило | По умолчанию |
|---|---|
| Можно не изгонять никого | вкл |
| Раскрывать роль выбывшего | вкл |
| Открытое голосование | вкл |
| Дон в игре | выкл |

**Таймеры**

| Фаза | Диапазон | По умолчанию |
|---|---|---|

| Шаг ночи (режим ведущего) | 8–60 с | 20 с |

Кроме пресетов можно ввести своё значение в этих границах.

## Режим ведущего

Отдельный режим для игры **за одним столом**. Вместо одной общей ночи роли
просыпаются по очереди, и сайт проговаривает вслух, кому открывать глаза.

Порядок шагов строится из **настроек комнаты**, а не из живых игроков: засыпание
→ мафия → доктор → шериф → маньяк. Мёртвую роль сайт зовёт так же, как живую, и
её шаг длится случайное время — иначе тишина выдала бы, что роль выбыла
(см. [ENGINEERING.md §5](ENGINEERING.md)).

Каждый шаг: объявление → окно хода → три секунды тишины, чтобы сходивший успел
закрыть глаза. Фраз «роль засыпает» нет намеренно — тот, кто сходил, и так
понимает, что пора.

**Голос.** Синтез речи браузера, русский голос из системы устройства. Выбирается
в лобби хостом; озвучку можно включить у себя на любом телефоне, но если
включить на нескольких, они заговорят вразнобой. Своих аудиозаписей нет: реплики
называют игроков по именам, записью это не покрыть. Если русского голоса в
системе нет, интерфейс говорит об этом прямо, а ночь идёт по шагам молча.

# Общее для обеих игр

- **Вход по коду** — шесть символов, одно поле на главной: сервер сам
  определяет, чья это комната.
- **История партий** обеих игр в одном списке. Незавершённую можно открыть и
  доиграть.
- **Итоги**: у Алиаса счёт по командам, у Мафии — кто кем был, чья победа и
  хроника ночей.
- **«Сыграть так же»** — новая комната с теми же правилами.
- **«Убрать из своей истории»** — карточка пропадает только у нажавшего; у
  остальных участников партия остаётся.
- **Пауза и переподключение** — обрыв связи не роняет партию.
- **Передача комнаты**: если хост вышел сам — права сразу переходят тому, кто
  на связи, включая зрителя. Если пропал по сети — через минуту комнату можно
  забрать кнопкой из меню игры.
- **Меню игры**: пауза и завершение партии у хоста, выход из партии у всех,
  захват комнаты — когда хоста нет в сети.
- **Кто не в сети** видно на всех экранах: аватар гаснет, под именем подпись.
