## 📖 О проекте

Две многопользовательские игры с серверной игровой логикой, защитой от
подглядывания и продуманной отказоустойчивостью. Без регистрации: хост
создаёт комнату, остальные заходят по 6-символьному коду.

Проект собран как **монорепозиторий из трёх пакетов** и разворачивается
**одной командой на одном сервере** — базы, оба приложения и реверс-прокси
поднимаются в Docker. Фронтенд и WebSocket-сервер делят общий
типизированный контракт, поэтому клиент и сервер физически не могут
«разъехаться» по формату событий.

## ✨ Что внутри

### 🎤 Алиас

- 🌐 **Онлайн** — каждый со своего телефона, слово видит только объясняющий
- 📱 **Локально** — одно устройство на компанию, передаётся по кругу
- ⏱️ **Живой таймер** — отсчёт ведёт сервер, у всех идёт синхронно
- 🧩 **10 категорий, 629 слов**, 2–6 команд, настраиваемые время и цель
- ✅ **Сверка итогов раунда** — спорные слова поправляются перед передачей хода
- ⏸️ **Пауза, переподключение, история партий**

### 🕵️ Мафия

- 🎭 **6 ролей** — мафия, дон, шериф, доктор, маньяк, мирный; состав считается
  автоматически или задаётся вручную
- 🌙 **Автоведущий** — сервер сам ведёт ночь, утро, обсуждение и голосование
- 🔒 **Роль видишь только ты** — полный расклад никогда не покидает сервер
- 🗳️ **Голосование с переголосованием** при ничьей и последним словом
- 👻 **Режим зрителя** с живой лентой событий, **хроника партии** в финале
- ⏸️ **Пауза**, переподключение, передача комнаты, «сыграть ещё» тем же составом
- 👥 **5–16 игроков**

### 🛠️ Под капотом

- 🔄 **Серверные машины состояний** — фазы считает сервер, клиент только рисует
- 🔐 **Персональный вид для каждого игрока** — в Мафии сервер собирает свой
  `MafiaView` на каждый сокет; чужой роли нет в передаваемых данных, а не просто
  «не показана»
- 🪪 **HMAC-токены** для авторизации WebSocket
- ⚡ **Redis для «горячего» состояния + Postgres для истории**
- ⏰ **Таймеры переживают перезапуск** — дедлайн дублируется в снапшоте
- 🧪 **55 юнит-тестов + smoke-сценарии** на настоящих сокет-соединениях
- 🐳 **Весь прод в одном `docker compose`**

## 🏗️ Архитектура

```
                        🌐 Браузер
                            │
                        HTTPS / WSS
                            │
                   ┌────────▼────────┐
                   │      Caddy      │  TLS, единственный порт наружу
                   └───┬─────────┬───┘
             /socket.io│         │остальное
                   ┌───▼───┐ ┌───▼───┐
                   │  ws   │ │  web  │
                   │Socket.│ │Next.js│
                   │  io   │ │ + API │
                   └───┬───┘ └───┬───┘
                       └────┬────┘
                   ┌────────┴────────┐
             ┌─────▼─────┐    ┌──────▼─────┐
             │ PostgreSQL│    │   Redis    │
             │  история  │    │  комнаты   │
             └───────────┘    └────────────┘
```

| Сервис | Роль | Почему так |
|---|---|---|
| **Caddy** | Прокси и TLS | Сам получает и продлевает сертификат; web и ws на одном домене — CORS не возникает |
| **web** | Страницы + REST `/api/*` | Отдаёт интерфейс и работает с БД |
| **ws** | Постоянные WebSocket-соединения | Отдельный процесс: фронт можно перезапустить, не роняя партии |
| **PostgreSQL** | Долговременные данные | Переживает перезагрузки |
| **Redis** | Состояние идущей комнаты | Фаза, таймер, роли; TTL 24 часа |

Порты баз наружу не публикуются — только внутренняя сеть Docker.

## 🔐 Как устроена защита

**Слово в Алиасе** уходит адресно — только сокету объясняющего. Остальные
получают карточку «X объясняет» и счётчик.

**Роли в Мафии** живут в полном снапшоте на сервере. Клиенту он не уходит
никогда: для каждого игрока собирается персональный вид, где заполнено
только то, что ему положено знать — своя роль, напарники (если он мафия),
результаты своих проверок (если шериф). Журнал партии с ролями погибших
получают лишь выбывшие и зрители. На это есть отдельные тесты, которые
проверяют **сериализованный ответ**, а не только типы.

## 🚀 Запуск локально

```bash
npm install
npm run setup:local   # поднимет базы в Docker, применит миграции, зальёт словарь
npm run dev           # web :3000 + ws :3001
```

Открыть **http://localhost:3000**

> 📱 С телефона в той же сети: `http://<IP-вашего-ПК>:3000` — LAN-доступ
> уже настроен.

Скопируйте `.env.example` в `.env`, если его ещё нет.

## 🧪 Проверка

```bash
npm run check                      # типы + юнит-тесты
npm run smoke:mafia -w @alias/ws   # партия Мафии на 6 клиентов
npm run smoke:game  -w @alias/ws   # полный раунд Алиаса
```

Smoke-сценарии работают против запущенного `npm run dev` и поднимают
настоящие сокет-соединения — это замена ручному прогону в шести вкладках.

## 🐳 Продакшн

```bash
cp .env.example .env && chmod 600 .env   # заполнить значения

docker compose -f docker-compose.prod.yml up -d postgres redis
docker compose -f docker-compose.prod.yml run --rm migrate
docker compose -f docker-compose.prod.yml run --rm seed
docker compose -f docker-compose.prod.yml up -d --build
```

Обновление — `./deploy.sh` (pull → сборка → миграции → перезапуск).

Пока домена нет, `SITE_ADDRESS=:80` открывает сайт по IP. С доменом
достаточно поменять эту переменную — сертификат Caddy выпустит сам.

## 🎮 Как играть

| Шаг | Алиас | Мафия |
|---|---|---|
| **1. Создать** | Хост настраивает комнату → получает код | Хост выбирает роли и таймеры |
| **2. Собраться** | Игроки заходят по коду или QR | То же, от 5 человек |
| **3. Играть** | Объясняющий видит слово, жмёт «Угадал» на время | Ночь, утро, обсуждение, голосование — ведёт сервер |
| **4. Итог** | Первая команда до цели побеждает | Побеждает город, мафия или маньяк |
